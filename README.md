# PowerRec

Свой Action Button: двойное и тройное нажатие кнопки питания запускают выбранные действия (нужен root).

## Как собрать
**Android Studio:** File → Open → папка проекта, подождать синхронизацию, Build → Build APK(s).
APK будет в `app/build/outputs/apk/debug/app-debug.apk`.

**GitHub:** залить папку в репозиторий, во вкладке Actions скачать артефакт `PowerRec-apk`.

## Как пользоваться
1. Установить APK, открыть приложение.
2. Нажать «Включить двойное нажатие питания», разрешить микрофон и уведомления.
3. В окне Magisk / KernelSU выдать приложению root-доступ.
4. В настройках приложения выбери действие на двойное и на тройное нажатие: запись звука, фонарик, камера, скриншот или любое приложение по имени пакета.
5. Во время записи любое двойное нажатие останавливает её.

Если на тройное нажатие стоит «Ничего», двойное срабатывает сразу. Если там что-то выбрано, двойное ждёт 0,7 секунды, чтобы отличить его от тройного.

Записи лежат в `Android/data/com.example.powerrec/files/records/`.
Выключи для приложения оптимизацию батареи, иначе система может усыпить службу.
После перезагрузки телефона надо один раз открыть приложение и снова нажать «Включить».
